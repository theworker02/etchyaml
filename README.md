# etchyaml

Etch and reshape yaml text streams with deterministic transforms.

**Site:** https://theworker02.github.io/etchyaml/

## Install / run

```bash
git clone https://github.com/theworker02/etchyaml.git
cd etchyaml
node src/cli.js
node --test
```
